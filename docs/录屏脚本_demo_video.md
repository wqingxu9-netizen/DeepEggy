# demo_video 录屏脚本（3 分钟）

> 适用于提交页「demo_video（选交材料）」。目标：3 分钟内把「扫码 → 拍配料表 → 解读 → 索引 → 溯源 → 分享」走完，不出现姓名/学号。
> 录屏工具：OBS（窗口捕获，1080p/30fps）或 Win+G / QQ 录屏都行。导出 MP4，控制在 100MB 内。

## 录制前 5 分钟

1. 浏览器**无痕窗口**打开 https://182-92-231-87.sslip.io/ ，Ctrl+F5 强刷（避免旧缓存）
2. 关掉所有通知（系统 + 微信 + QQ），隐藏书签栏（Ctrl+Shift+B）
3. 输入法切成英文，鼠标移动放慢、点击后停半秒
4. 准备好两张素材：一张**条码**（如脉动 6902000100029 的条形码）、一张**配料表照片**（手机里提前拍好）
5. 窗口按 16:9 摆好，页面缩放 100%，地址栏不要出现个人信息

## 分镜（总 180 秒）

| 时间 | 画面 | 操作 / 口播（可不配音，用字幕） |
|---|---|---|
| 0:00–0:12 | 首页 | 停在首页两秒。字幕：「超市货架前，配料表看不懂？」「拍一下，30 秒说明白。」 |
| 0:12–0:45 | 扫码解读 | 点「扫条码」→ 选内置示例（脉动 / 阿萨姆奶茶）→ 等结果。先给「能不能喝」的结论，再往下滚：每味配料的大白话解释 |
| 0:45–1:10 | 量化折算 | 切到「营养」Tab：把糖、盐、油折成方糖和盐勺。字幕：「一勺糖是多少，直接告诉你」 |
| 1:10–1:35 | 拍配料表 | 返回首页 →「拍配料表」→ 选那张照片 → OCR 识别 → **核对页**（低置信词高亮，点确认）→ 出结果 |
| 1:35–2:00 | 话术拆穿 + 过敏提醒 | 切到「话术」：展示「0 蔗糖 ≠ 无糖」的对照；再切「我的情况」，勾一个过敏原，看提醒变化 |
| 2:00–2:25 | 商品索引 | 首页滚到「商品索引 共 543 款」→ 点一个品类（如「薯片」）→ 选一条（如乐事薯片）→ 展示它也走同一条解读链路 |
| 2:25–2:45 | 溯源 | 在结果里切「溯源」：标准号、生产商、产地、备案条码。字幕：「配料表之外，还能对上国标和生产商」 |
| 2:45–3:00 | 分享卡片 | 点「生成分享卡片」→ 卡片出现 → 停住。字幕：「发给家人，一句话说清该不该买。」收尾：「网页版已上线，打开即用」 |

## 录制要点

- **不要念稿**：3 分钟很紧，字幕 + 慢操作比配音稳；要配音就压在 2 分半以内留白。
- **每步只展示一个重点**：结果页 7 个 Tab 不用全点，挑「配料 / 营养 / 话术 / 溯源」四个。
- **等待时间剪掉**：AI 解读 10–30 秒，录完剪掉等待段，或开着「正在解读」的加载态做转场。
- **失败兜底**：万一联网/LLM 超时，先用内置示例（脉动、元气森林、阿萨姆奶茶、力量帝）重录，这几款走本地库不依赖网络。
- **合规**：画面里不要出现真实姓名、学校、学号、微信头像；个人信息页（「我的情况」）只勾过敏原，不填真实病史。
