## 二、想验收什么，看哪里

| 溯源能力实测数据 | `docs/开发日志.md` 的"渠道验真"表格 |
| 时间线（是否全部开赛后产出） | `docs/文件时间清单.csv`，或跑 `python scripts/file_timeline_check.py` |
| 设计迭代过程 | `.hallmark/log.json`、`backups/` |

## 三、运行方式

- **一键起服务**：`python -m app.backend.main`（默认 80 端口，环境变量 `PORT` 可改）
  - 需要 `DEEPSEEK_API_KEY`（AI 解读用）
  - 前端静态 + `/api/trace` + `/api/analyze` + `/api/scan-barcode` 一起跑
- **前端单独预览**：`cd app/frontend && python -m http.server 8000`
- **OCR**：`app/backend/ocr.py` 由队友提供（契约见 `docs/后端接口说明.md`）；未提供时 `/api/ocr` 返回 501，前端降级为手动输入
- **溯源命令行**：`python -m app.backend.trace --demo`
- **字段抽取模型**：`app/backend/label_ner.py` 可离线加载 `data/models/label_ner_model.json` 推理

## 四、约定与注意事项

1. **git**：已 `git init`，首次提交待定（赛期内完成，作者 `DeepEggy`）。
2. **.gitignore 已排除**：`__pycache__/`、`*.pyc`、`.venv/`、`.env`、`data/raw/`、`data/processed/`、`data/trace_cache.sqlite`、`*.log`。
3. **`data/trace_cache.sqlite`**（约 14 MB）是搜索缓存，随时可删、可重建，不参与提交。
4. **`backups/`** 是旧版本前端证据，保留不删，用于说明视觉迭代过程。
5. 涉及真实照片、企业溯源等结论时，以开发日志记录的口径为准：**没有证据不编造**，未验证项明确标注。
6. **API Key 不写入前端与仓库**：服务器用 systemd 环境变量，本地用环境变量传入。
