## 四、使用说明

### 抓取脚本

```bash
# 预览（不写文件，先看能抓多少）
python scripts/fetch_brands.py --preview

# 正式入库（自动备份原库 + 条码去重）
python scripts/fetch_brands.py --apply
```

必须带 `--preview` 或 `--apply` 参数。想加新品牌：改脚本顶部 `BRANDS` 列表后重跑。

### 数据生效规则

后端启动时缓存商品库，**改完数据必须重启后端**才生效：

```bash
PORT=8080 python -m app.backend.main
```

验证：浏览器打开 `http://127.0.0.1:8080/api/products`，看 `total` 是否为 1128。

### 回滚

```bash
copy data\openfoodfacts_cn.json.bak data\openfoodfacts_cn.json
# 然后重启后端
```
