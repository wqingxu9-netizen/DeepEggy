## 生成方式（可复现）

用 Dashi PPT 的内容 + 主题管线生成，出图与选稿脚本在 `scripts/`：

| 脚本 | 用途 |
|---|---|
| `deck_variants.py` | 遍历 4 个排版方案，逐页截图，方便挑版 |
| `deck_pick.py` | 按指定方案组合设置每页版式并截图确认 |
| `deck_dark.py` | 把预览页逐页切到深色配色 |
| `deck_shots.py` | 逐页截图拼对照表，做出片验收 |

素材全部来自真机截图（`shots/`），不生成假图；不含姓名、学号等个人信息。

> 说明：`output/` 是这套流程的构建中间态（goal.json、fill-plan、预览服务缓存），已加进 `.gitignore`，不入库。
